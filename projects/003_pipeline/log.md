# 003_pipeline — log.md

## 소요시간 (세션 기준, 대략)
- 기획(concept.md) + 대본(script.json) 직접 작성: ~15분
- TTS(EdgeTtsProvider) + 발음사전 적용: 1회 실행, 즉시
- cast-builder(scene-3): 명령 정의 추가 + 1회 실행, 즉시
- Studio 녹화(scene-1): **2회 재작업** — 아래 "막힌 지점" 참고. 총 3회 녹화(첫 실패 2회 + 성공 1회)
- Pexels b-roll(scene-2): 1회 실행, 즉시
- 렌더: 2회(스튜디오 캡처 재작업 때문에 재렌더 1회 발생), 각 3초 내외

## 막힌 지점 — Studio 녹화의 "얼어붙은 도입부" 문제 (신규 발견 버그)
002에서 만든 `generate-studio-capture.ts`를 003의 훅 씬(4.6초, 002의 데모 씬보다 훨씬 짧음)에
그대로 썼더니 문제가 드러남:

1. **원인**: 녹화 시작(context 생성) → 페이지 로드 → 2초 하이드레이션 대기 → Play 클릭 →
   실제로 타임라인이 움직이기까지 약 4초가 걸림(Remotion Player 자체 기동 지연 포함).
   기존 스크립트는 이 4초짜리 "얼어붙은 첫 프레임"을 그대로 잘라서 씬에 물렸음 —
   002의 10초짜리 씬에서는 티가 안 났지만(전체의 40%만 정적), 003의 4.6초짜리 훅 씬에서는
   씬 대부분(4초/4.6초)이 정지 화면이 되어버림.
2. **수정**: `LEAD_IN_SECONDS=4`만큼 잘라내는 후처리 추가. 단, `-c copy`(스트림 복사)로
   자르면 VP8 웹엠이 키프레임을 거의 안 찍어서(녹화 시작 시점에 딱 1개) 잘라낸 지점부터
   디코딩할 키프레임이 없어 완전히 빈(흰색) 프레임만 나옴 — **재인코딩**(`-c:v libvpx`)으로
   바꿔서 해결.
3. **부수 발견**: Studio를 실제 script.json으로 띄우면, 캡처 대상 씬에 "이전 실행에서 남은"
   assetPath가 이미 있을 경우 Studio 자신의 프리뷰가 그 파일(마침 덮어써지는 중인 깨진 파일)을
   재생하려다 흰 화면을 녹화에 담아버리는 재귀적 문제도 있었음 → 캡처용 props는 항상
   해당 씬의 `assetPath`를 제거한 임시 복사본으로 띄우도록 수정(원본 script.json은 안 건드림).
4. 두 수정 모두 `generate-studio-capture.ts`에 반영해 재사용 가능한 상태로 커밋 —
   다음에 짧은 씬에 Studio 녹화를 붙일 때 같은 문제를 다시 겪지 않음.

## 다음 개선점
- `LEAD_IN_SECONDS`(4초)는 이번 환경에서 측정한 경험값 — 머신 성능에 따라 달라질 수 있어
  더 견고한 방법(타임라인 프레임 카운터를 폴링해서 실제 재생 시작을 감지)으로 바꿀 여지 있음.
- C유형(빅넘버/빅아이콘) 모션그래픽 컴포넌트는 여전히 미구현 — 이번엔 checklist로 대체.
  004 이전에 한 번은 만들어볼 만함(효과/수치 강조 씬에서 반복적으로 아쉬움).
- b-roll 키워드 선정을 지금은 CLI 인자로 수동 지정 — 씬 수가 늘어나면 스크립트 생성 단계에서
  후보 키워드까지 같이 뽑아주는 게 편할 수 있음(단, 지난 세션에 "스키마 필드 추가는 안 한다"로
  이미 결정했으므로 스키마 밖에서 처리하는 방법을 고민할 것).

## 002 대비 비주얼 다양성 평가
002는 씬 6개 중 다크 터미널/텍스트 위주 비중이 높다는 게 v4 피드백이었음. 003은 씬 6개를
다음처럼 배정: Studio 녹화(훅) / Pexels 인물 b-roll(기획) / cast-builder 터미널(스크립트 생성,
code 타입) / pipeline 모션그래픽(렌더링) / checklist 모션그래픽(효과) / pulse 모션그래픽(아웃트로).
실사 캡처 2종 + 코드 모션그래픽 3종 + 터미널 1종으로 갈려서, 같은 비주얼이 연속되는 구간이
없음 — 다만 마지막 3개 씬(렌더링/효과/아웃트로)이 전부 "코드 모션그래픽 계열"이라는 점은
여전히 개선 여지(C유형 컴포넌트가 생기면 씬5가 갈릴 수 있음).
