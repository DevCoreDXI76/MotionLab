# 프로젝트명

**모션랩 (MotionLab)** — 채널명 확정(2026-09-08). 유튜브 채널 개설 시 이 이름 사용.
(검토했던 다른 후보: "빌더로그", "코드씬(CodeScene, 상표 충돌 우려로 제외)", "1인개발 실험실")

---

## 배경 (한 줄 요약)

김부장 모션툰 채널(본편)과는 별도로, Claude+Remotion 등 신기술을 활용한 자동화 콘텐츠 제작 역량을 쌓고 기록하는 사이드 트랙. 처음부터 "완성 후 김부장 채널에 스핀오프로 연결"을 전제로 설계하되, 통합은 반응 검증 후 단계적으로 진행한다.

---

## 목표

1. **1차 목표 (개인/기술)**: Claude+Remotion 기반 자동화 영상 제작 파이프라인을 실제로 구축하고 학습한다. 필요하면 3D, AI 실사 영상 등 신기술 실험도 이 트랙 안에서 자유롭게 시도한다.
2. **2차 목표 (배포)**: 완성된 콘텐츠를 유튜브(쇼츠/롱폼)와 인스타그램 릴스에 동시 배포한다. 릴스 전용 별도 기획은 하지 않음 — 크로스포스팅 수준으로 제한.
3. **3차 목표 (연결, 조건부)**: 김부장 채널과의 교차 노출을 통해 오디언스 중첩 여부를 검증하고, 근거가 쌓이면 정식 스핀오프로 편입한다.

**명시적으로 목표가 아닌 것**: 이 트랙 자체의 조회수/구독자 극대화, 광고 수익화. 이 트랙은 실험·학습·기록이 우선이며, 채널 성장 KPI는 김부장 본편에 걸려 있다.

---

## 운영 원칙

- **본편(김부장) 리소스와 분리**: 이 트랙은 본편의 백로그(LoRA 착수, 중반부 이탈 조사, 파이프라인 안정화 잔여 항목)를 밀어내지 않는다. 시간 배분은 본인 재량이되, 본편 백로그가 장기간 정체되면 이 트랙이 잠식하고 있는 건 아닌지 스스로 점검한다.
- **본편 서사·포맷은 건드리지 않는다**: 김부장 시리즈의 소재, 그림체(모노크롬 웹툰풍), 애니메이션 포맷은 그대로 유지한다. 이 트랙에서의 신기술 실험(3D, AI 실사 영상 등)이 본편에 역으로 침투하지 않도록 경계를 지킨다.
- **완성 기준은 사전에 정의**: "완성되면 연결"이라는 계획의 모호함을 없애기 위해, 아래 완성 기준 중 최소 조건을 채우기 전에는 본편과 통합하지 않는다.
  - 콘텐츠 3~5편 이상 제작 완료
  - 최소한의 일관된 포맷(길이, 톤, 썸네일 스타일 등)이 자리 잡음
- **연결은 2단계로 진행**:
  1. **1단계 (즉시 가능)**: 김부장 영상 설명란/엔딩 카드에 이 트랙 링크만 노출. 교차 클릭률을 실측 데이터로 확보.
  2. **2단계 (조건부)**: 1단계 클릭률이 유의미하면(예: 설명란 클릭률이 채널 평균 대비 뚜렷이 높으면) 재생목록 통합, "스핀오프" 정식 편입 검토. 유의미하지 않으면 완전 별도 채널 유지로 방향 전환.

## 스코프 (이 프로젝트에서 다룰 것 / 다루지 않을 것)

**다룬다**
- Claude+Remotion 기반 영상 자동화 파이프라인 설계·구현
- 3D/실사 AI 영상 등 신기술 실험 및 학습 기록
- 유튜브+릴스 동시 배포를 위한 포맷/스펙 정리
- 콘텐츠 기획(제작 과정 자체를 소재로 한 정보/브이로그성 콘텐츠)

**다루지 않는다**
- 김부장 본편 파이프라인 수정/개선 (해당 논의는 기존 모션툰 스튜디오 프로젝트에서)
- 이 트랙만의 별도 광고 수익화 전략
- 릴스 전용 별도 기획/촬영

## 현재 상태 (2026-08-25 갱신)

파이프라인 1차 설계·구축은 끝났고, **완성 기준(콘텐츠 3편)을 005로 달성**했다:

- **파이프라인**: 기획→스크립트(Claude 직접 작성)→TTS(EdgeTtsProvider)→터미널 캡처(cast-builder)→
  b-roll(Pexels)/Studio 녹화(Playwright)→Remotion 렌더→메타데이터 초안까지 전 단계 구축·검증 완료.
  상세는 `remotion_트레이드오프_claudecode인계.md`(결정 로그), `002_test_리뷰_개선백로그.md`(비주얼
  품질 리뷰 v1~v5 + 정책 갱신) 참고.
- **완성 기준 — 콘텐츠 3~5편**: 002_test(파이프라인 검증용 테스트 렌더, 미카운트) →
  003_pipeline(1편) → 004_failures(2편) → **005_casting(3편) — 3편 게이트 달성**.
  5편 게이트까지 최대 2편 남음.
- **완성 기준 — 포맷 일관성**: 6씬 구조(title→talkingPoint→code→talkingPoint→talkingPoint→outro),
  쇼츠(1080×1920) 포맷으로 003~005 모두 동일하게 유지됨.
- **비주얼 소스 정책**: 004부터 Pexels b-roll이 title/talkingPoint/outro 씬의 기본값(code 씬만
  cast-builder 터미널 유지). 005부터는 감정 비트 b-roll을 얼굴 대신 손·화면 클로즈업으로
  기본 전환(004 리뷰에서 인물 불연속성·화보톤 문제 확인 → 정책 수정 → 005로 유효성 검증 완료).
  Studio 녹화(Playwright)는 도구는 남아있으나 선택 사항으로 낮춤.
- **아웃트로 다양화**: 005부터 `visual.cue`로 모션그래픽 variant를 편마다 다르게 선택(001~004는
  `pulse` 고정 → 005는 `pipeline`). 새 컴포넌트 없이 기존 4종(`pipeline`/`terminal`/`checklist`/
  `pulse`) 재활용.
- **롱폼 파생**: 아직 미착수(1차 확정 사항대로 쇼츠 먼저, 필요해지면 착수).
- **유튜브 채널 개설(2026-09-08)**: `@MotionLab.coredxi`로 개설 완료.
- **003~006 업로드 완료(2026-09-09)**: `scripts/youtube_upload.py`로 4편 전부 비공개(private)
  업로드, "모션랩 빌드로그" 재생목록 포함. 썸네일은 `<id>.thumbnail.png`까지는 자동 생성되지만
  채널이 전화번호 미인증 상태라 API 설정은 403으로 실패 — youtube.com/verify 인증 후 재시도
  예정(수동 Studio 업로드로도 가능). 공개 전환은 아직 미판단.
- **연결 1단계(김부장 채널 설명란 링크 노출)**: 미착수 — 여전히 미판단 항목(아래 참고).
- **3편 게이트 판정 완료(2026-09-03)**: 003·004·005 사용자 직접 시청 확인(005는 오프닝 훅
  "004" 편 번호 단독 언급 문제 발견 → 수정·재렌더 후 재확인) 후, **메타 시리즈(파이프라인
  구축 과정 자체를 다루는) 포맷을 계속 유지하기로 결정**. 5편 게이트까지 기계적으로 밀어붙이지
  않고 이 시점에 방향을 확정함 — 006도 같은 포맷/소재 계열로 진행.
