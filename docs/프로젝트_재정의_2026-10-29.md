# 모션랩(MotionLab) 프로젝트 재정의 — 2026-10-29

*2026-10-29 브레인스토밍 세션 결과. 8/15 설정 문서(`remotion_사이드트랙_프로젝트설정.md`)를 대체하는 2기 운영 기준. 아래 "프로젝트 지침 교체본" 절을 프로젝트 instructions에 그대로 붙여넣어 사용.*

## 1. 왜 재정의하는가 (진단)

- 8/15 목표(1차 파이프라인 구축 / 2차 배포 / 3차 김부장 연결)는 문서상 대부분 달성됐다. 003~007 5편 업로드, 썸네일, 재생목록, 김부장 설명란 링크(10/18)까지 완료.
- 그러나 007(9/11) 이후 7주간 신규 산출물 0건. 원인은 시간 부족보다 **"달성됐다고 기록된 것과 실제로 하고 싶었던 것의 불일치"**다.
  - 5편은 파이프라인 1회 완주가 아니라 "Claude가 도와준 반수작업 제작"이었다. 대본은 사람이 직접 작성, b-roll은 매 편 수동 재검색·검수, 터미널 cast 명령은 편마다 수동 추가. (업로드는 `scripts/youtube_upload.py`로 API 자동화됨 — 이 부분만 자동.)
  - AI 실사 이미지·AI 영상·3D 씬 실험은 "파이프라인 안정화 이후"로 미뤄졌는데, 안정화 선언이 없어 영원히 시작되지 않는 구조였다.
- 5편 게이트는 완성 기준이었지 지속 기준이 아니었다. 게이트를 넘긴 뒤 다음 코스가 없었다.

## 2. 새 목표 (단일)

> **AI 비주얼을 쓴 008편을, 사람 개입 2곳(소재 선정·최종 검수)만 남기고 파이프라인으로 완주한다.**

이 한 문장이 2기의 유일한 능동 목표다. 원래 하고 싶었던 두 가지("파이프라인을 제대로 돌려보기", "AI 실사·3D가 얼마나 나오는지 보기")를 한 편으로 증명하는 것이 완성이다.

### 능동 목표에서 내려 "수동(passive) 상태"로 둔 것
- **인스타 릴스 크로스포스팅** — 2개월간 0회. 008 완주 후 여유가 있으면 1회 시도, 아니면 그대로 둔다.
- **김부장 채널 연결 2단계 판단** — 10/18 설명란 링크가 이미 걸려 있으므로 데이터는 알아서 쌓인다. 12월 중순(링크 노출 8주) 시점에 MotionLab 채널 외부 유입 추이를 한 번 보고 판단한다. 그 전엔 손대지 않는다.
- **편수·주기 목표** — 없앤다. "N주에 1편"은 2기에 존재하지 않는다.

### 명시적으로 목표가 아닌 것 (8/15와 동일)
조회수·구독자 극대화, 광고 수익화.

## 3. 2단계 계획

### 1단계 — 비주얼 스파이크 (2주 타임박스: 10/29 ~ 11/12)

파이프라인은 건드리지 않는다. 쇼츠로 만들지도 않는다. 산출물은 **샘플 파일 + 판정**뿐이다.

| 실험 | 만들 것 | 판정 질문 |
|---|---|---|
| A. AI 실사 이미지 | 기존 b-roll 쓰임새(손·화면 클로즈업, 얼굴 없음)를 대체할 정지 이미지 3~5장 | Pexels b-roll 대신 쓸 수 있는가? 스타일 일관성이 잡히는가? 장당 비용·시간은? |
| B. AI 영상 클립 | 3~5초 클립 1~2개 (image-to-video 또는 text-to-video) | 쇼츠 1컷으로 넣어도 어색하지 않은가? 생성 실패율은? |
| C. 3D 씬 | Remotion 안에서 돌아가는 3D 씬 1개 (예: React Three Fiber 기반 간단한 오브젝트/카메라 무브) | 코드 모션그래픽을 대체·보강할 수 있는가? 렌더 시간이 감당되는가? |

- 각 실험은 하루~이틀 안에 끝낸다. 막히면 "아직 아님"으로 판정하고 넘어간다 — 스파이크의 목적은 완성이 아니라 판정이다.
- 결과는 `projects/008_*/spike/` 아래 샘플 파일과 `spike_verdict.md`(실험별 쓸 만함 / 아직 아님 / 조건부 + 근거 한 줄 + 비용·시간)로 남긴다.
- 기존 비주얼 정책(b-roll-first, 감정 비트는 손·화면 클로즈업, 얼굴 금지)과 항목 15 화면 캡처 보안 규칙은 스파이크에도 그대로 적용된다.
- **1단계 종료 조건**: 11/12까지 세 실험 모두 판정이 나왔거나, 타임박스가 끝났다. 둘 중 먼저 오는 쪽.

### 2단계 — 파이프라인 완주 (11/13 ~ 12월 중, 008편)

1단계에서 "쓸 만함" 판정을 받은 비주얼 방식을 ③에셋 준비 단계에 꽂고, 남은 수동 지점을 자동화해 008편을 완주한다. 세 실험 모두 "아직 아님"이면 비주얼은 현행(코드 모션그래픽 + Pexels)으로 두고 파이프라인 완주만 한다 — 그것도 유효한 결과다.

자동화해야 할 수동 지점 (현재 → 목표):

| 단계 | 현재 | 2기 목표 |
|---|---|---|
| ② 대본 | 사람이 script.json 직접 작성 | `templates/script_prompt_template.md` 기반 Claude 생성 → 스키마 검증 통과 시 그대로 사용 (항목 12 "완전 자동" 쪽으로 확정) |
| ③ 비주얼 | Pexels 검색 → 사람이 해상도·인물·중복 검수 (다양성·얼굴 클로즈업 배제는 커밋 a6c84dd·34d875f로 이미 자동화) | 1단계 판정에 따라 AI 생성 또는 Pexels. 남은 사람 검수 단계를 제거 |
| ③ 터미널 cast | 편마다 SCENE_COMMANDS 수동 추가 | script.json의 code 씬에 명령을 필드로 넣고 cast-builder가 읽게 변경 |
| ⑤ 렌더 | 자동 | 유지 |
| ⑥ 업로드 | `youtube_upload.py` 자동 | 유지. 썸네일·메타데이터 생성도 같은 실행에 포함 |

- 사람이 개입하는 곳은 **① 소재 선정(concept.md 작성)**과 **⑦ 최종 검수(업로드 직전 mp4·썸네일 육안 확인, 비공개→공개 전환)** 두 곳뿐이다.
- 008 소재는 1단계 스파이크 자체(무엇을 시도했고 뭐가 됐고 뭐가 안 됐는지)로 한다 — 기존 메타 콘텐츠 기조 유지, 새 소재 발굴에 시간 쓰지 않음.

## 4. 완성 기준과 종료 조건

**완성 기준 (2기 종료 = 성공)**
- 008편이 concept.md 입력 → 대본 → TTS → 비주얼 → 렌더 → 썸네일·메타데이터 → 업로드(비공개)까지 **사람 개입 없이** 통과하고, 사람은 최종 검수 후 공개 전환만 한다.
- `projects/008_*/log.md`에 사람 개입 지점이 2곳 이하로 기록된다.
- 1단계 `spike_verdict.md`가 존재한다 (세 실험 모두 "아직 아님"이어도 완성 조건 충족).

**종료 조건 (2기 종료 = 중단 선언)**
- 11/12까지 1단계 실험이 하나도 착수되지 않았다면, 이 트랙은 동기가 없는 것으로 보고 **1기 종료 선언 + 채널 포트폴리오 동결**로 전환한다(10/29 세션 A안). 질질 끌지 않는다.
- 2단계가 12/31까지 완주되지 않으면 같은 판단을 한다.

**완성 이후** (이 문서의 범위 밖, 완주 후 별도 세션에서)
- 파이프라인을 코어디엑스아이 쇼케이스·설명 영상 등 외부 용도로 전용할 가능성(10/29 세션 B안)을 열어 둔다. 결정이 아니라 선택지 보존.
- 김부장 연결 2단계는 12월 중순 데이터로 판단.
