## 실물 캡처 구현 — 시도 이력과 확정 방식

**시도 이력**: ① vhs — Windows go-rod 행, 포기 ② PowerSession — TTY 미연결로 실패, 포기 ③ ffmpeg gdigrab — **보안 사고**(사용자 실제 데스크톱 캡처, 민감정보 포함, 파일 즉시 삭제) → 에이전트 자동 화면 캡처 전면 금지(인계 문서 항목 15).

**확정 방식**: 터미널 컷 = cast-builder(실제 출력 + 합성 타이밍 → `.cast` → `TerminalScene` 재생, v4에서 검증 완료). GUI 컷 = 사람이 Game Bar(Win+Alt+R, 활성 창만)로 수동 녹화 → `assets/captures/` 투입 → 육안 검수 후 소비.

## 에셋 소스 확장 3안 — v4 피드백 대응 (2026-08-16)

v4의 "터미널 일변도"를 벗어나기 위한 신규 소스. 모두 항목 15(화면 캡처 금지)와 양립.

**① Remotion Studio 동작 화면 — Playwright 페이지 녹화 (무료, 자동화 가능, 권장 1순위)**
- Playwright의 `recordVideo`는 **에이전트가 직접 띄운 브라우저 페이지의 뷰포트만** 기록한다 — 데스크톱 캡처가 아니므로 항목 15 위반이 아님(캡처 범위가 구조적으로 한정됨).
- Remotion Studio는 localhost 웹앱 → Playwright로 열고 재생/타임라인 스크럽/props 조작을 스크립트로 연출하며 녹화 → webm을 에셋으로 투입.
- "Remotion이 실제로 동작하는 화면" 요구를 직접 충족. 렌더 진행률 등 터미널 쪽은 cast-builder가 이미 커버.
- 규칙: 로그인된 서비스(claude.ai 등)는 녹화 금지 — 파이프라인이 띄운 로컬 앱만.

**② 실사 b-roll — Pexels Video API (무료, 자동화 가능, 권장 2순위)**
- 무료 API, 상업적 사용 가능·저작자표시 불요 라이선스. 세로(portrait) 필터 지원.
- `visual.cue`에 `broll: {keywords: [...]}` 추가 → API 검색·다운로드 → `OffthreadVideo` 풀블리드 배경.
- 용도: 공감 컷(문제 제기 씬의 "지친 크리에이터", 키보드 타이핑, 시계 등) 씬당 1~2컷. 범용 스톡 느낌이 나므로 배경 분위기용으로 한정, 백본은 여전히 실물 캡처.

**③ AI 영상 생성 — 실험 트랙 개시 (유료, 훅 전용 1컷부터)**
- 프로젝트 1차 목표에 명시된 "AI 실사 영상 실험"을 여기서 개시하는 것. 2026-08 시세(초당): Kling 3.0 $0.09~0.14, Sora 2 ~$0.10, Veo 3.1 Fast $0.15(네이티브 오디오), Runway Gen-4.5 ~$0.20, Veo 3.1 Standard $0.40. 훅용 4~8초 컷이면 편당 $0.5~3 수준.
- 용도: 훅 씬 전용 콘셉트 숏(예: "영상이 스스로 조립되는" 이미지). 스톡이 못 주는 고유함 확보. 스타일 일관성 리스크 관리를 위해 편당 1컷 한정으로 시작.
- 벤더는 TTS와 동일하게 어댑터 패턴으로: `videoGenProvider.generate(prompt, duration) → clipPath`.

**씬 타입별 최종 소스 매핑(안)**: 훅 = AI 생성 콘셉트 숏 or Studio 동작 화면 / 문제 제기 = 실사 b-roll(공감 컷) / 솔루션·데모 = cast-builder + Studio 녹화 + 펀치인 / 정리·아웃트로 = 빅 타이포 + 파일트리 빌드업.
