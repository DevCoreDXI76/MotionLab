## 이미지 컷 + 동적 모션 방향 (2026-08-16 논의)

- **Remotion 측**: `KenBurnsImage` 류 래퍼 컴포넌트 — 정지 이미지에 팬/줌(scale/translate interpolate) 적용. 씬 duration에 맞춰 자동 계산. 정적 이미지 1장 = 동적 컷 1개가 됨.
- **에셋 소스 우선순위** (v1 리뷰와 동일): ① 파이프라인 부산물 화면 캡처(터미널/코드/Studio) ② 코드 기반 모션그래픽(다이어그램·아이콘) ③ 스톡 API ④ AI 생성(2차 트랙).
- **파이프라인 측**: `script.json`의 `visual.cue`를 소비하는 asset resolver — 씬별로 이미지 경로를 해석해 컴포넌트에 주입. 소스 교체 가능하게 추상화.
