## 작업 1 — 백로그 1~4 수정

### 1-1. 자막 분리: 소수점에서 끊지 않기
- 파일: `remotion/src/lib/splitSubtitleLines.ts`(+ `.test.ts`)
- 현재 `split(/(?<=[.!?。!?\n])\s*/)`가 "빼자 1.7배"를 "빼자 1." / "7배"로 자른다.
- 기준: 숫자 사이의 `.`(예: `1.7`, `3.14`, `v2.0`)에서는 자르지 않는다. 문장 끝 `.`(뒤가 공백·줄끝)은 지금처럼 자른다.
- 테스트 최소 4개: `"속도가 1.7배 느려졌어요. 끝."` → 2줄 / `"버전 2.0을 썼다."` → 1줄 / `"3.14와 2.5를 비교. 다음."` → 2줄 / 기존 테스트 전부 유지.

### 1-2. 길이: 60초 이하 강제
- 008은 템플릿의 "400~550자" 지시에도 66.9초가 나왔다. 프롬프트 지시만으로는 안 지켜진다(D8 교훈: 금지는 코드에).
- 구현:
  - 템플릿 목표를 **350~480자**로 낮춘다(`templates/script_prompt_template.md`).
  - 대본 검증(`scriptSchema`/`validateScript`)에 나레이션 총 글자수(공백 제외) **상한 480자** 규칙 추가 → 초과 시 기존 재생성 루프로 되돌아간다.
  - narration 단계 뒤에 **실측 게이트**: 씬 durationMs 합이 **59,000ms 초과**면 초과량을 피드백에 넣어 script 단계부터 재생성(최대 2회). 3회째도 초과면 실패로 멈춘다. 자동 재시도는 사람 개입이 아니다.
- 테스트: 481자 대본 검증 실패 / 59,001ms 합계면 게이트가 재생성 신호를 낸다 / 재시도 상한.

### 1-3. 썸네일: 내용이 다 보이는 프레임
- 파일: `remotion/scripts/lib/thumbnail.ts`(+ `.test.ts`)
- 현재 규칙(첫 `code` 씬 중간, 없으면 전체의 40%) 때문에 008은 불릿이 1개만 보이는 프레임이 잡혔다.
- 새 규칙(우선순위): ① `title` 씬이 있으면 그 씬의 **85% 지점**(애니메이션 완료 후) ② 없으면 불릿이 있는 첫 씬의 **90% 지점**(불릿 전부 등장 후) ③ 둘 다 없으면 기존 40% 폴백.
- 테스트: 위 3경우 + 008 script.json 구조로 ①이 선택되는지.

### 1-4. outro 고정 문구 제거
- 008 script.json `ctaText: "다음 편에서 계속"`처럼 대본 생성이 다음 편을 약속하는 문구를 넣는다.
- 구현: `ctaText`를 스키마에서 선택(optional/null 허용)으로, 템플릿에 "concept.md가 다음 편을 명시하지 않으면 다음 편 예고 문구를 쓰지 말 것" 추가, 검증에서 `다음 편` 포함 시(concept에 없으면) 재생성. `OutroScene`은 ctaText가 없으면 해당 줄을 렌더하지 않는다.
- 테스트: ctaText null 렌더 props 통과 / "다음 편" 포함 대본 검증 실패.

사람이 한 일은 두 가지뿐이다: 무엇을 만들지 고르기, 다 만든 걸 보고 승인하기. 그 사이 일곱 단계는 명령 한 번으로 전부 첫 시도에 통과했다. 비용은 0원.

정보성 쇼츠, 45~60초. 훅은 "사람 손 두 번, 5분 44초". 이전 편 번호는 쓰지 않는다. 다음 편 예고 문구는 쓰지 않는다.
